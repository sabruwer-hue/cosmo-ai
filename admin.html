System boundaries

Cosmo's chat gateway currently retrieves approved training lessons, active knowledge records and missions. Saving a record here makes it persistent; approving a lesson makes it eligible for retrieval. Neither action guarantees that a model has learned it perfectly. We will add evaluations and retrieval traceability as the next engineering layer.

Admin authentication is checked by the cosmo-admin-gate Edge Function against the server-side owner email secret. If that secret has not been added yet, the portal remains locked.
